Borg

A synth unit that switches drumlogued to run extensions in place. Select the unit and fire GateOn(): the daemon re-executes itself under an embedded preload object, same pid, with no rootfs writes. A power cycle restores everything.

Extensions

  • A status menu, opened with MUTE and MASTER.
  • An optional MIDI note and velocity transform.

Build

Requires podman and a logue-sdk checkout.

LOGUE_SDK_PATH=~/Projects/logue/logue-sdk ./build-drum.sh borg_drumlogue

Output: bin/borg.drmlgunit.

Install and use

  1. Copy borg.drmlgunit to userfs/Units/Synths/ on the instrument.
  2. Load the unit on a part.
  3. Save the program, so the daemon reloads it after the switch.
  4. Fire GateOn().
