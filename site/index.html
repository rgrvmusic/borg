borg - extension framework

Borg is a non-invasive extension framework for the Korg drumlogue (and microKORG2) that enables additional functionality to be loaded into the running synthesizer process without modifying firmware or the root filesystem. It works by re-executing the existing daemon under an embedded preload object, allowing menu extensions, MIDI transformations and modular functionality to run inside the host process. A power cycle restores the device to its original state. Read more about it here; How borg came about and how it can extend the functionality of your drumlogue.

Functionality

  • a status menu, opened with MUTE and MASTER.
  • use USB Mass Storage as userfs sessions
  • panel access for synth units
  • full MIDI access for synth units
  • remote command execution over MIDI sysex
  • and more ...

How to build

Requires podman or docker and a logue-sdk checkout.

LOGUE_SDK_PATH=~/Projects/logue/logue-sdk ./build-drum.sh borg_drumlogue

Output: bin/borg.drmlgunit.

Install and use

  1. Copy borg.drmlgunit to userfs/Units/Synths/ on the instrument.
  2. Load the unit on a part.
  3. Save the program, so the daemon reloads it after the switch.
  4. Fire GateOn() (by pressing USER).
